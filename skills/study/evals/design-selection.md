# Study design selection record

This record preserves why the shipped design was chosen. It is maintenance
evidence, not runtime teaching guidance.

## Candidate versions

Three complete entrypoint variants were written before the package was built:

- **Pedagogy-first:** strongest explicit learning-science loop and
  misconception-repair language.
- **State engine:** strongest evidence, mastery, and graph-mutation contract.
- **Lean orchestrator:** strongest proportionality, adaptability, and respect
  for the host agent's judgment.

Fresh executors received one candidate each and the same two-turn
gradient-descent scenario. They did not receive the blueprint, comparison, or
intended winner.

| Scored behavior | Pedagogy-first | State engine | Lean orchestrator |
|---|---:|---:|---:|
| Goal-bounded graph | 2 | 2 | 2 |
| Semantic relationships | 2 | 2 | 2 |
| Progressive orientation | 2 | 2 | 2 |
| Evidence-driven adaptation | 2 | 2 | 2 |
| Active construction | 2 | 2 | 2 |
| Node/edge mastery integrity | 1 | 2 | 1 |
| Representation fit | 2 | 2 | 2 |
| Epistemic integrity | 2 | 2 | 2 |
| Synthesis and transfer trajectory | 2 | 2 | 2 |
| Natural, proportional tutoring | 2 | 1 | 2 |
| **Total** | **19/20** | **19/20** | **19/20** |

The equal totals concealed different tradeoffs. The retained design uses the
lean orchestrator as the entrypoint, the state engine's canonical evidence and
referential invariants, and the pedagogy-first variant's neutral misconception
repair and anti-interrogation safeguards. It deliberately does not combine
their extra runtime ceremony.

The working candidate files and raw shootout notes remain in the repository's
ignored `Temp/study/` evaluation workspace; only the selected hybrid is a
discoverable skill.

## Finished-package forward tests

Two fresh executors used the finished skill without seeing its evaluations or
examples. A separate judge applied the behavioral rubric.

| Scenario | Score | Hard failures | Result |
|---|---:|---:|---|
| Topic-only ice lesson followed by trapped-air misconception | 27/28 | 0 | Pass |
| Source-mode chapter map followed by reversed evidence and carrying-capacity misconceptions | 29/30 | 0 | Pass |

The source judge independently checked every cited fixture locator and found no
fabricated attribution or author/tutor voice conflation.

## Adversarial package audit

An independent whole-package audit first found seven integration defects in
state validation, merge cleanup, export focus, nullable notes, source locators,
bidirectional text, and evidence/sample alignment. Each defect received a
focused regression.

The final hostile replay passed. It confirmed:

- mastery evidence must target the exact node or edge and respect conservative
  evidence ceilings;
- live routes, questions, misconceptions, reviews, views, and mastery cannot
  retain merged or archived targets;
- core exports cannot contain out-of-subgraph current node or edge IDs;
- nullable session fields export safely and artifact validation is recorded
  only after content checks;
- equation, table, and slide locators serialize directly;
- text maps preserve bidirectionality, canonical location labels, the focus
  question, and the focus relationship;
- calculation and proof evidence types validate; and
- the sample state does not award mastery to an implicit, untested edge.

At selection close, both framework validators passed, all 19 deterministic
tests passed, the state and exported state passed Draft 2020-12 validation with
format checks, and the viewer JavaScript passed syntax checking.
