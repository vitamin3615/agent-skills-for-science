# Anticipate Reviewer Concerns Guide

## Purpose

During editing, proactively identify and flag issues that reviewers will likely challenge. Don't just polish prose—anticipate problems before submission.

**Philosophy:** The best edit is one that prevents reviewer criticism. Every manuscript will be scrutinized by experts looking for weaknesses. Your job is to find them first.

---

## MANDATORY Pre-Edit Examination

**Before making any edits, scan the manuscript for these common reviewer triggers:**

---

## 1. Overclaims (High-Frequency Reviewer Target)

### What to Flag:

- "We demonstrate..." for correlative data
- "Proves that..." without mechanism data
- "First study to..." without literature verification
- "Groundbreaking/transformative/paradigm-shifting"
- Claims in Abstract stronger than Results support
- "Dramatic/substantial/significant" without quantification

### Editing Action:

- Replace "demonstrate" → "show" or "suggest" where appropriate
- Replace "prove" → "provide evidence that" or "support"
- Add qualifiers: "in this model," "under these conditions"
- Ensure Abstract claims match Results exactly
- Request evidence or soften claim

### Example Edit:

**Before:** "We demonstrate that X is essential for Y"
**After:** "Our data suggest that X contributes to Y in this model"

---

## 2. Missing Comparisons

### What to Flag:

- No comparison to gold standard (e.g., primary cells)
- No comparison to existing methods
- No comparison to prior work on same topic
- Isolated findings without context

### Editing Action:

- Flag need for comparison data
- Add citation to relevant comparisons
- Note in margin: "Reviewers will ask how this compares to [X]"
- Suggest adding comparison statement even if data not available

### Example Flag:

> **EDITOR NOTE:** Reviewers will ask how these iPSC-hepatocytes compare to primary human hepatocytes. Even if direct comparison isn't available, add a statement contextualizing values relative to published PHH data.

---

## 3. Unsubstantiated Novelty Claims

### What to Flag:

- "Novel" without literature support
- "First" without exhaustive search
- "Unique" for common approaches
- Missing citations to related work

### Editing Action:

- Request literature search verification
- Add recent relevant citations
- Soften claim if cannot verify: "To our knowledge..."
- Replace "novel" with specific differentiation

### Example Edit:

**Before:** "We present a novel approach to..."
**After:** "We present an approach that differs from prior work [refs] by specifically..."

---

## 4. Control Gaps

### What to Flag:

- Drug treatments without vehicle controls mentioned
- Genetic manipulations without scrambled/non-targeting controls
- No wild-type or untreated comparisons shown
- Positive controls absent
- Negative controls absent

### Editing Action:

- If controls exist but not described, add description
- If controls missing, flag as critical gap
- Request control data or acknowledge limitation
- Ensure control data shown in figures

### Example Flag:

> **CRITICAL:** Vehicle control data not shown for drug treatment in Fig. 3. Reviewers will require this. Please add vehicle control group to figure or state why not applicable.

---

## 5. Statistical Weaknesses

### What to Flag:

- N not specified for experiments
- "n=3" that might be technical replicates
- Statistical test not specified
- Multiple comparisons without correction
- P-value without test named
- Bar graphs without individual data points

### Editing Action:

- Request N clarification (biological vs technical)
- Add statistical test names
- Verify multiple testing correction
- Request individual data points be shown
- Ensure Methods describes statistical approach

### Example Flag:

> **FLAG:** Figure 2 shows n=3 but doesn't clarify if these are biological or technical replicates. Reviewers will require this distinction. Please clarify in legend.

---

## 6. Claims-Evidence Mismatch

### What to Flag:

- Text describes result differently than figure shows
- Quantification doesn't match "representative" image
- Abstract claims not supported by Results
- Discussion extrapolates beyond data

### Editing Action:

- Reconcile text to match figures exactly
- Request corrected images or corrected text
- Ensure Abstract reflects actual results
- Limit Discussion speculation to one paragraph

### Example Edit:

**Text claims:** "expression was comparable to primary hepatocytes"
**Figure shows:** Expression 40% of primary hepatocyte levels
**Action:** Revise to "expression reached approximately 40% of primary hepatocyte levels"

---

## 7. Mechanistic Overclaims

### What to Flag:

- "X regulates Y" from correlation only
- "Mechanism" section with no mechanism data
- Pathway claims without pathway experiments
- "Direct" interaction claimed without direct evidence

### Editing Action:

- Replace "regulates" → "is associated with" for correlation
- Acknowledge mechanistic limitations
- Change "mechanism" header if speculative
- Remove "direct" unless biochemically demonstrated

### Example Edit:

**Before:** "This mechanism explains how X regulates Y"
**After:** "These data are consistent with a model where X contributes to Y, though the mechanism requires further investigation"

---

## 8. Missing Methodology Details

### What to Flag:

- Methods section lacks detail for reproducibility
- Key parameters not specified
- Statistical methods vague
- Reagent information incomplete
- N and replication not specified per experiment

### Editing Action:

- Request specific parameters
- Add standard information (cell passage, animal age, etc.)
- Ensure statistical methods fully described
- Verify reagent table is complete
- Add experiment-specific N to Methods

### Example Flag:

> **FLAG:** Antibody concentrations and incubation times not specified. Reviewers require this for reproducibility. Please add to Methods.

---

## 9. Generalizability Issues

### What to Flag:

- All data from single cell line/model
- No replication across conditions
- Human relevance unclear for model organisms
- Claims of general applicability without evidence

### Editing Action:

- Acknowledge single-model limitation
- Request or suggest additional model data
- Add explicit limitation statement
- Soften generalizability claims

### Example Edit:

**Before:** "This demonstrates that X is important in disease"
**After:** "This demonstrates that X contributes to disease phenotypes in this mouse model; validation in additional models and human samples will be important"

---

## 10. Figure Issues

### What to Flag:

- "Data not shown" claims
- Scale bars missing
- Axis labels unclear
- No individual data points in bar graphs
- Color-only distinction (accessibility)
- Low resolution images

### Editing Action:

- Request data be shown or statement removed
- Add scale bars
- Clarify axis labels
- Request individual points
- Add shape distinctions for colorblind accessibility
- Request higher resolution figures

---

## Editing Workflow Integration

### Phase 1 (Document Assessment):

- Scan for all 10 concern categories
- Create prioritized list of flags

### Phase 2 (During Editing):

- Address flags that can be fixed editorially
- Mark flags requiring author input
- Note flags for cover letter/response letter

### Phase 3 (Final Review):

- Verify all critical flags addressed
- Ensure remaining flags acknowledged as limitations
- Check that softened claims are consistent throughout

---

## Flag Severity Levels

| Level          | Definition                                   | Action                         |
| -------------- | -------------------------------------------- | ------------------------------ |
| **CRITICAL**   | Reviewers will reject without this           | Must address before submission |
| **MAJOR**      | Significant concern, likely revision request | Address or clearly acknowledge |
| **MINOR**      | Likely reviewer comment, not fatal           | Address if possible            |
| **SUGGESTION** | Would strengthen paper                       | Implement if easy              |

---

## Communication with Authors

### For Critical Flags:

> "Reviewers will likely require [X]. I recommend adding [specific data/statement] before submission. This is a common rejection criterion at high-impact journals."

### For Major Flags:

> "This may prompt reviewer concern. Consider adding [X] or explicitly acknowledging this limitation in the Discussion."

### For Minor Flags:

> "A reviewer may note that [X]. Consider adding a brief statement addressing this."

## Quick Reference: The 10 Anticipation Areas

1. **Overclaims:** Is language calibrated to evidence?
2. **Comparisons:** Are standard benchmarks included?
3. **Novelty:** Is "first/novel" actually verified?
4. **Controls:** Are all controls shown and described?
5. **Statistics:** Is N adequate and clearly biological?
6. **Claims-Evidence:** Does text match figures exactly?
7. **Mechanism:** Is causation claimed from correlation?
8. **Methods:** Is reproducibility ensured?
9. **Generalizability:** Are limitations acknowledged?
10. **Figures:** Are all visualization standards met?

**Before completing any edit, verify you've examined ALL 10 areas.**
