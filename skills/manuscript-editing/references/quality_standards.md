# CNS-Level Quality Standards

**Role in Skill:** This defines the TARGET—10 essential quality gates that CNS-level papers must meet.

**Distinct from:** `meta-anticipate-reviewer-concerns.md` (PROCESS for flagging problems during editing)

**When to use:** As a quality benchmark to evaluate whether manuscript meets CNS standards.

## 10 Essential Quality Gates

### ✅ 1. Multiple Validation Methods

- Major claims: ≥2 independent approaches
- Causality: Genetic + pharmacological
- Validation: In vitro + in vivo
- **Why it matters:** Single-method claims are insufficiently robust for CNS journals

### ✅ 2. Statistical Rigor

- All quantitative claims: n = X (or referenced in Figure/Table)
- All comparisons: P values (or referenced in Figure/Table)
- All tests: Named explicitly (or referenced in Figure/Table)
- All error bars: s.d. or s.e.m. defined
- **Example:** "(n = 6 mice; P = 0.032...)" OR "significantly increased (Fig. 2A)"

### ✅ 3. In Vivo Confirmation

- Key findings validated in organisms
- Disease models where applicable
- Physiological relevance demonstrated
- **Critical for:** Claims about biological processes, disease mechanisms, therapeutic potential

### ✅ 4. Literature Comparison

- Findings positioned vs. prior work
- Novelty explicitly stated
- Contradictions addressed
- Citations comprehensive (10-30 in intro)
- **Pattern:** "Consistent with...", "In contrast to...", "Extending previous work..."

### ✅ 5. Limitations Acknowledged

- Honest constraint assessment
- Alternative interpretations considered
- Generalizability discussed
- Technical limitations stated
- **Location:** Discussion section, typically paragraph 4

### ✅ 6. Clear Research Gap

- "However, ... remains unclear"
- Specific, not generic gap
- Connected to this study
- **Location:** End of Introduction paragraph 2-3

### ✅ 7. Mechanistic Depth

- HOW/WHY explained, not just WHAT
- Molecular players identified
- Causal relationships demonstrated
- Biological logic explained
- **Standard:** Must go beyond phenomenology to mechanism

### ✅ 8. Active Voice & Precision

- "We found" not "it was found"
- Specific numbers not "many"
- Technical terms defined
- Quantitative specificity
- **Examples:** "increased 3.2-fold" not "greatly increased"

### ✅ 9. Consistent Terminology

- Same terms throughout
- Acronyms defined first use
- No unexplained synonym switching
- **Common error:** Switching between "AT2 cells" and "alveolar cells" without clarification

### ✅ 10. Future Directions Clear

- Specific next steps
- Logical extensions
- Feasible experiments
- Unanswered questions explicit
- **Location:** Discussion final paragraphs

## Common Disqualifying Issues

**Automatic Concerns:**

- Missing n values or statistical tests (if not in Figures)
- Single-method claims for major conclusions
- No in vivo validation (for physiological claims)
- Vague/unsupported claims
- Inconsistent terminology

**Major Weaknesses:**

- Weak literature positioning
- No mechanistic depth
- Missing limitations
- Overgeneralization
- Passive voice predominance

## Quality Scoring Rubric

Rate each gate on a 1-5 scale:

- **5** = Exceeds CNS standards
- **4** = Meets CNS standards
- **3** = Acceptable but could be strengthened
- **2** = Needs improvement
- **1** = Critical deficiency

**Minimum acceptable score:** Average ≥ 3.5 across all gates

**Critical gates** (must score ≥ 4):

- Gate 2: Statistical Rigor
- Gate 7: Mechanistic Depth
- Gate 8: Active Voice & Precision

## Section-Specific Quality Markers

### Abstract Quality Markers

✓ 150-250 words
✓ All 8 structural elements present
✓ No citations
✓ Quantitative specificity ("3.2-fold", "68%", "n = 8")
✓ Impact clearly stated

### Introduction Quality Markers

✓ Funnel structure (broad → specific)
✓ 10-30 citations
✓ Explicit research gap
✓ Clear "Here we..." statement
✓ Connects to Results

### Results Quality Markers

✓ Every claim has n and P value (or references Figure)
✓ Every figure panel referenced
✓ Multiple methods for major claims
✓ Quantitative precision throughout
✓ Declarative subheadings

### Discussion Quality Markers

✓ Positioned vs. literature
✓ Mechanistic interpretation
✓ Limitations acknowledged
✓ Future directions specific
✓ Appropriate hedging for interpretations

### Methods Quality Markers

✓ Complete reproducibility
✓ All reagents: vendor + catalog
✓ Statistical methods comprehensive
✓ Regulatory approvals stated
✓ Data availability declared

### Figure Legend Quality Markers

✓ Self-contained descriptions
✓ All panels described
✓ Sample sizes present
✓ Error bars defined
✓ Scale bars specified
