# Metacognitive Checklist for Manuscript Editing

**Purpose:** This checklist ensures you edit with independent thinking, self-awareness, and strategic judgment rather than mechanical template-application.

**When to use:** Apply this checklist at THREE critical phases:
1. **BEFORE EDITING:** Diagnostic self-interrogation
2. **DURING EDITING:** Active self-monitoring
3. **AFTER EDITING:** Critical self-evaluation

---

## Phase 1: BEFORE EDITING - Diagnostic Questions

### ✓ Understanding Check: Core Message

**Question:** "Do I understand the author's central finding and voice?"

**Self-assessment checklist:**
- [ ] I can summarize the main finding in one sentence
- [ ] I recognize the author's writing style (formal/informal, technical/accessible, concise/detailed)
- [ ] I understand the target audience (specialists/general scientists/clinical researchers)
- [ ] I know which claims are central vs. peripheral
- [ ] I can identify the author's key innovation or novel contribution

**Red flags:**
- ❌ I'm not sure what the main point is
- ❌ I haven't identified the author's voice characteristics
- ❌ I don't know what level of technical detail is appropriate
- ❌ I'm unclear which findings are most important to the author

**CRITICAL:** If ANY red flags present:
1. STOP - Do not begin editing yet
2. RE-READ - Carefully review the original text again
3. ANALYZE - Identify the core message and author's style before proceeding

---

### ✓ Context Check: Section Purpose

**Question:** "Do I understand this section's role in the overall manuscript?"

**Self-assessment checklist:**
- [ ] I know what this section type must accomplish (Abstract = complete story; Results = data presentation; etc.)
- [ ] I understand how this section connects to preceding/following sections
- [ ] I recognize what information readers need at this point in the narrative
- [ ] I can identify structural requirements specific to this section

**Red flags:**
- ❌ I'm treating all sections identically
- ❌ I'm applying generic editing without section-specific awareness
- ❌ I don't know what readers expect at this narrative position

**CRITICAL:** If red flags present:
- Review section-specific guidelines BEFORE editing
- Consider narrative flow and section function

---

### ✓ Data Integrity Check: Information Inventory

**Question:** "Have I catalogued all factual content before editing?"

**Self-assessment checklist:**
- [ ] I've identified all numbers, percentages, fold-changes in the original
- [ ] I've noted all statistical values (n, P values, test names)
- [ ] I've catalogued all citations and references
- [ ] I've marked all causal claims and their strength
- [ ] I've noted all experimental methods mentioned

**Red flags:**
- ❌ I'm starting to edit without inventorying original data
- ❌ I might not notice if I accidentally change a number
- ❌ I haven't verified what information exists vs. what's missing

**CRITICAL:** If red flags present:
1. CREATE INVENTORY - List all numbers and citations before editing
2. USE AS REFERENCE - Check inventory after editing to ensure nothing changed

**See also:** Information Integrity Protocol (references/integrity-protocol.md) for comprehensive validation.

---

### ✓ Bias Awareness Check: Editing Tendencies

**Question:** "Am I aware of my editing biases and tendencies?"

**Self-assessment checklist:**
- [ ] I recognize when I tend to over-edit (changing too much)
- [ ] I'm aware if I favor certain sentence structures
- [ ] I know if I tend to add unnecessary jargon
- [ ] I understand my style preferences vs. objective improvements

**Common editor biases to watch:**
- **Complexity bias:** Adding technical language to "sound more scientific"
- **Uniformity bias:** Making all sentences follow the same pattern
- **Completeness bias:** Adding details the author intentionally omitted
- **Academic formality bias:** Making casual writing unnecessarily formal

**Red flags:**
- ❌ I'm going to make this "sound more professional" (style-forcing)
- ❌ I want to standardize all sentence structures (homogenization)
- ❌ I think the author should have included X detail (scope expansion)

**CRITICAL:** If red flags present:
- Distinguish between MUST change (errors, vagueness) vs. PREFER to change (style differences)
- Default to minimal editing when uncertain

---

## Phase 2: DURING EDITING - Active Self-Monitoring

### ✓ Edit Quality Check: Enhancement vs. Homogenization

**Question:** "Is each edit adding precision/clarity or imposing my style?"

**Self-assessment checklist:**
- [ ] Each edit adds quantitative precision (specific numbers, statistics)
- [ ] OR each edit clarifies ambiguous/vague meaning
- [ ] OR each edit fixes grammatical/structural errors
- [ ] I'm preserving the author's sentence structures when they're already clear
- [ ] I'm NOT adding jargon unnecessarily
- [ ] I'm NOT making simple things complex
- [ ] My edits make the text MORE readable, not more impressive-sounding

**Red flags:**
- ❌ I'm changing sentences that were already clear and precise
- ❌ I'm imposing uniform structure across all paragraphs
- ❌ I've added technical terms the author didn't use (without necessity)
- ❌ I've made the text sound "more scientific" but less readable
- ❌ I'm editing >50% of words in a paragraph without clear errors

**CRITICAL:** If >50% word changes in a paragraph:
1. STOP - This likely indicates over-editing
2. RESET - Return to original text
3. ASSESS - Identify MINIMAL necessary changes
4. DISTINGUISH - What MUST change vs. what I WANT to change
5. APPLY - Only essential edits

---

### ✓ Voice Preservation Check: Author Recognition

**Question:** "Would the author still recognize their writing style?"

**Self-assessment checklist:**
- [ ] The basic sentence structures match the original style
- [ ] The level of formality is preserved
- [ ] The author's preferred terminology is retained (when accurate)
- [ ] The narrative flow feels like an enhanced version, not a rewrite
- [ ] Field-specific conventions are respected

**Voice preservation test:**
- Read original sentence aloud
- Read edited sentence aloud
- Ask: "Do these sound like the same person wrote them?"

**Red flags:**
- ❌ The tone has shifted dramatically (casual → overly formal, or vice versa)
- ❌ Every sentence now follows the same template structure
- ❌ The author's characteristic phrases have been replaced with generic ones
- ❌ I've translated simple language into complex academic jargon

**CRITICAL:** If voice is changing:
- Revert to original phrasing
- Add only essential precision (numbers, statistics)
- Keep author's structural choices when effective

---

### ✓ Information Integrity Check: Data Preservation

**Question:** "Am I preserving every piece of original information?"

**MANDATORY during-editing checks:**
- [ ] I have NOT changed any numbers (not even rounding)
- [ ] I have NOT added any statistics that weren't in the original
- [ ] I have NOT added citations from my knowledge
- [ ] I have NOT changed claim strength ("suggests" → "demonstrates")
- [ ] I have NOT removed caveats, limitations, or hedging
- [ ] I have NOT added interpretations not in the original

**Red flags:**
- ❌ I'm tempted to "add the P value since it's probably < 0.05"
- ❌ I'm changing "associated with" to "regulates" (strengthening claim)
- ❌ I'm removing "may" or "suggest" to make claims sound stronger
- ❌ I'm adding methodological details I inferred but weren't stated
- ❌ I'm removing a caveat because it "weakens the claim"

**CRITICAL:** If ANY temptation to add/change data:
1. STOP IMMEDIATELY
2. REVERT - Return to exact original information
3. FLAG - Note missing element in editorial summary for author
4. NEVER FABRICATE

**Remember:** You are an EDITOR, not a CO-AUTHOR. You enhance clarity, not content.

---

### ✓ Claim Calibration Check: Evidence Matching

**Question:** "Do verb strengths match the evidence presented?"

**Self-assessment checklist:**
- [ ] Correlation data uses "associated with," "correlates with" (NOT "regulates," "causes")
- [ ] Loss-of-function uses "required for," "necessary for" (NOT "sufficient for")
- [ ] Gain-of-function uses "sufficient for," "can induce" (NOT "required for")
- [ ] Mechanistic evidence uses "demonstrates," "shows" (NOT "proves" unless very strong)
- [ ] Preliminary data uses "suggests," "consistent with" (NOT "demonstrates")
- [ ] Model systems specify "in this model" (NOT overgeneralized to humans)

**Red flags:**
- ❌ I'm strengthening verbs without checking the evidence ("Our data show" → "prove")
- ❌ I'm using causal language for correlational data
- ❌ I'm weakening strong claims that have solid mechanistic evidence
- ❌ I'm not calibrating claims to the actual experiments described

**CRITICAL:** If uncertain about claim strength:
- Check the 7-Question Framework, Question 7: Claim Calibration Matrix
- Default to preserving original claim strength unless clearly miscalibrated

---

### ✓ Over-Editing Detection: Volume Check

**Question:** "Am I editing productively or compulsively?"

**Quantitative thresholds:**
- **<25% word changes:** Appropriate for already-good writing
- **25-50% word changes:** Acceptable for moderate improvements
- **>50% word changes:** WARNING - Likely over-editing or style-forcing
- **>75% word changes:** CRITICAL - This is rewriting, not editing

**Self-assessment checklist:**
- [ ] Most sentences require only 1-2 changes
- [ ] I'm making targeted improvements, not wholesale rewrites
- [ ] I'm adding information (statistics) more than changing structure
- [ ] Some sentences remain completely unchanged (because they're already good)

**Red flags:**
- ❌ I've rewritten almost every sentence
- ❌ I'm changing sentences just because "I would have written it differently"
- ❌ I can't find anything acceptable in the original
- ❌ I'm on my third pass and still finding things to change

**CRITICAL:** If >50% changes:
1. STOP EDITING
2. COMPARE - Original vs. edited side-by-side
3. IDENTIFY - Which changes are essential vs. preferential
4. REVERT - Keep only essential changes
5. ACCEPT - Good writing doesn't need to be perfect or match your style

---

### ✓ Emotional Awareness Check: Editing Motivations

**Question:** "What's driving my editing choices—objective improvement or subjective preference?"

**Healthy editing motivations:**
- ✅ This is vague and could be misinterpreted (clarity)
- ✅ This lacks quantification (precision)
- ✅ This has a grammatical error (correctness)
- ✅ This transition is abrupt (flow)
- ✅ This claim is too strong for the evidence (calibration)

**Problematic editing motivations:**
- ❌ "This doesn't sound sophisticated enough" (status anxiety)
- ❌ "I would never write it this way" (ego)
- ❌ "This is too simple" (complexity bias)
- ❌ "This needs more technical language" (jargon addiction)
- ❌ "This should match the style of the previous paragraph" (uniformity obsession)

**Self-reflection prompts:**
- "Why am I making this change?"
- "Does this edit serve the AUTHOR or serve MY preferences?"
- "Would this change be obvious to any editor, or just me?"
- "Am I improving clarity or imposing my voice?"

**Red flags:**
- ❌ I feel uncomfortable with the author's casual style (personal discomfort)
- ❌ I want this to sound more like Nature papers I've read (template addiction)
- ❌ I think authors should always use complex constructions (ideology)

**CRITICAL:** If editing is driven by preference rather than necessity:
- Pause and distinguish objective improvements from style preferences
- Only apply changes that enhance precision/clarity objectively

## Phase 3: AFTER EDITING - Critical Self-Evaluation

### ✓ Message Preservation Check: Core Findings

**Question:** "Is the author's central message intact and recognizable?"

**Self-assessment checklist:**
- [ ] The main finding is stated exactly as in the original (enhanced but not altered)
- [ ] The novel contribution is clear and unchanged
- [ ] The key innovation remains prominent
- [ ] The take-home message is the same
- [ ] The author's excitement/emphasis on certain findings is preserved

**Verification test:**
- Read original paragraph
- Read edited paragraph
- Ask: "Do these make the same scientific claim?"

**Red flags:**
- ❌ The emphasis has shifted to different findings
- ❌ I've highlighted peripheral findings and downplayed central ones
- ❌ The innovation seems different than in the original
- ❌ I've changed what the author is most excited about

**CRITICAL:** If core message shifted:
1. REVERT to original
2. IDENTIFY where the shift occurred
3. EDIT MORE CONSERVATIVELY with focus on author's priorities

---

### ✓ Voice Recognition Check: Author Style

**Question:** "Would the author recognize their work and voice?"

**Self-assessment checklist:**
- [ ] The writing style feels familiar to the original
- [ ] The tone (formal/informal, technical/accessible) is preserved
- [ ] Characteristic phrases and terminology are retained where appropriate
- [ ] The sentence variety matches the original author's preferences
- [ ] The level of technical detail is consistent with original

**Voice recognition test:**
1. Show edited version to original author
2. Expected reaction: "This is my work, but clearer/more precise"
3. NOT: "This sounds like someone else wrote it"

**Red flags:**
- ❌ Every sentence now has identical structure (template-forced)
- ❌ Simple direct language replaced with complex academic constructions
- ❌ Author's informal style converted to rigid formality
- ❌ Field-specific terms replaced with generic scientific jargon
- ❌ The "personality" of the writing has vanished

**CRITICAL:** If voice is lost:
- This indicates over-editing and style-forcing
- Revert to original and apply minimal essential changes only

---

### ✓ Data Integrity Verification: Information Unchanged

**Question:** "Is every piece of original information still present and unchanged?"

**MANDATORY post-editing verification:**
- [ ] All numbers match the original EXACTLY (no rounding, no approximation)
- [ ] All citations are preserved UNCHANGED
- [ ] All statistical values (n, P, test names) are from original (none added)
- [ ] All claim strengths maintained ("suggests" still "suggests," not "demonstrates")
- [ ] All caveats and limitations preserved
- [ ] All hedging language retained where appropriate
- [ ] No interpretations added that weren't in the original

**Verification method:**
1. Create side-by-side comparison of original vs. edited
2. Highlight all numbers, citations, statistical terms in both
3. Verify EXACT matches
4. Check that nothing was added, removed, or modified

**Red flags:**
- ❌ I changed a claim from "associated with" to "regulates" (strengthened unjustifiably)
- ❌ I removed a "may" or "suggest" to sound more definitive
- ❌ I rounded "2.3-fold" to "2-fold" for simplicity
- ❌ I added "P < 0.05" because it seemed implied
- ❌ I removed a limitation because it "weakened" the claim

**CRITICAL:** If ANY data changed:
1. IMMEDIATE REVERT - This is the most serious editing violation
2. RESTORE - Return to exact original information
3. FLAG - Note missing elements for author in editorial summary
4. NEVER FABRICATE OR ALTER DATA

**See:** Information Integrity Protocol (references/integrity-protocol.md) for comprehensive post-editing verification.

### ✓ Edit Justification Check: Evidence-Based Changes

**Question:** "Can I justify every edit using the 7-Question Framework?"

**Self-assessment checklist:**
- [ ] Each edit addresses a specific question from the 7-Question Framework
- [ ] I can explain WHY each change improves the manuscript
- [ ] My edits are not based on arbitrary style preferences
- [ ] Every change has a clear purpose aligned with CNS-quality principles

**The 7-Question Framework justifications:**
1. **Hierarchy:** Did I improve the emphasis on strongest findings?
2. **Quantification:** Did I add specific numbers/fold-changes/percentages?
3. **Statistics:** Did I flag missing n, P values, or test names?
4. **Mechanism:** Did I improve integration of how/why explanations?
5. **Negatives:** Did I preserve or better present null/unexpected results?
6. **Flow:** Did I improve transitions and narrative progression?
7. **Calibration:** Did I fix claim strength to match evidence?

**Red flags:**
- ❌ I made changes "because it sounds better" (no framework justification)
- ❌ I edited for variety or stylistic preference (not framework-aligned)
- ❌ I can't explain which question from the framework this edit addresses
- ❌ Most of my edits are "just different ways of saying the same thing"

**CRITICAL:** If edits lack framework justification:
- These are likely preferential style changes, not objective improvements
- Remove edits that don't address the 7 questions
- Keep only changes with clear framework-based rationale

---

### ✓ Improvement Assessment: Value Added

**Question:** "Did I enhance precision/clarity or just change things?"

**Quantitative improvement categories:**

**1. Precision Added:**
- ✅ Added specific numbers: "increased" → "increased 2.3-fold"
- ✅ Added percentages: "most" → "78%"
- ✅ Added ranges: "variable" → "54-73% across time points"

**2. Clarity Enhanced:**
- ✅ Fixed ambiguous antecedents
- ✅ Improved parallel structures
- ✅ Clarified confusing syntax
- ✅ Defined technical terms

**3. Completeness Flagged:**
- ✅ Noted missing statistics in editorial summary
- ✅ Flagged incomplete methods for author
- ✅ Identified where validation might be needed

**4. Rigor Strengthened:**
- ✅ Ensured statistical notation complete
- ✅ Verified claim calibration to evidence
- ✅ Improved figure integration

**Non-improvement "changes" to avoid:**
- ❌ Synonym substitution without clarity gain
- ❌ Restructuring already-clear sentences
- ❌ Adding jargon for formality
- ❌ Changing tone/voice without purpose

**Self-assessment:**
- Count edits in each category
- If most edits are "non-improvements," you over-edited
- Valuable editing should mostly be precision/clarity/completeness/rigor

---

### ✓ Readability Check: Accessibility

**Question:** "Is the edited version easier to understand than the original?"

**Self-assessment checklist:**
- [ ] Sentences are clearer and more direct
- [ ] Technical terms are defined or contextualized
- [ ] Complex ideas are expressed as simply as possible (but not simpler)
- [ ] The narrative flow is smooth
- [ ] A scientist in a related field could follow the logic

**Readability test:**
- Read edited version aloud
- Ask: "Is this clearer than the original, or just more complex?"

**Red flags:**
- ❌ I've made sentences longer and more complex
- ❌ I've added technical jargon that requires specialized knowledge
- ❌ I've created convoluted constructions to sound sophisticated
- ❌ The edited version takes longer to read and understand
- ❌ I've prioritized formality over clarity

**CRITICAL:** If readability decreased:
- This is failed editing—clarity is paramount
- Simplify complex additions
- Return to more direct constructions
- Prioritize understanding over impressiveness

---

### ✓ Self-Critique: Honest Assessment

**Question:** "If I received this editing on my own manuscript, would I be grateful or annoyed?"

**Honest self-reflection:**
- **Grateful if:** You enhanced precision, fixed errors, clarified confusing parts, maintained my voice
- **Annoyed if:** You rewrote my work in your style, changed things unnecessarily, lost my voice, made it less readable

**Self-assessment prompts:**
- "Did I respect the author's intelligence and expertise?"
- "Did I treat their work as valuable, or as needing to be 'fixed'?"
- "Would I want this level of editing on my writing?"
- "Am I being helpful or condescending?"

**Red flags:**
- ❌ I've essentially rewritten most of the text
- ❌ I've imposed my preferences throughout
- ❌ The author would struggle to recognize their work
- ❌ I've "corrected" things that were stylistic choices, not errors

**CRITICAL:** If you wouldn't want this editing on your own work:
- You've likely over-edited and style-forced
- Revert to more conservative editing
- Respect the author's competence and voice

## Summary: Metacognitive Editing Principles

### The Three Essential Questions

**Before:** "Do I understand what I'm editing and why?"
**During:** "Am I enhancing or homogenizing?"
**After:** "Would the author recognize and appreciate this?"

### The Five Critical Self-Checks

1. **Data Integrity:** Nothing fabricated, nothing altered
2. **Voice Preservation:** Author's style maintained
3. **Edit Volume:** <50% word changes in most paragraphs
4. **Framework Justification:** Every edit addresses one of the 7 Questions
5. **Readability:** Edited version is clearer, not more complex

### Red Flag Response Protocol

**If ANY red flag detected at ANY phase:**
1. **STOP** - Pause editing immediately
2. **ASSESS** - Identify the specific issue
3. **CORRECT** - Revert or adjust as needed
4. **VERIFY** - Check that issue is resolved
5. **PROCEED** - Continue only when issue is fixed

### The Ultimate Test

**Ask yourself:** "Am I editing like an expert scientific editor who respects the author's work, or am I rewriting like a co-author imposing my preferences?"

**Expert editor mindset:**
- Enhances precision and clarity
- Preserves author voice and style
- Makes minimal necessary changes
- Respects author's scientific judgment
- Adds value without taking ownership

**Co-author mindset (avoid):**
- Rewrites in personal style
- Imposes structural preferences
- Makes extensive unnecessary changes
- Treats original as draft to be "fixed"
- Takes ownership of the text
