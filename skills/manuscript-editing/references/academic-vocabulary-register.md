# Academic Vocabulary and Register

**Core Principle:** Academic writing follows vocabulary conventions distinct from everyday English. Rather than providing word lists (which would be limiting), this guide activates the AI's inherent knowledge of CNS paper vocabulary conventions.

**The Goal:** Professional scientific communication that matches published Cell/Nature/Science papers—NOT pompous prose or artificially formal language.

## The Vocabulary Decision Framework

For each word choice, ask these three questions:

### 1. Would this word appear in a Cell/Nature/Science paper?

- If colloquial or informal → upgrade to academic register
- If already appropriate → preserve

### 2. Does this word convey the precise meaning?

- Precision > formality
- A simple precise word beats a fancy vague one

### 3. Does this word match the evidence/claim strength?

- Reporting verbs carry epistemic weight
- Links to Question 7 (Claim Calibration)

## Categories of Vocabulary Consideration

**Apply your knowledge of CNS paper conventions in these areas:**

| Category | Consideration | NOT About |
|----------|---------------|----------|
| **Reporting Verbs** | Match verb to evidence strength (observed, found, demonstrated, established) | Always choosing the strongest verb |
| **Hedging Language** | Appropriate epistemic modality (may, suggests, appears to, indicates) | Hedging everything or nothing |
| **Formal Register** | Avoiding colloquialisms and casual phrasing | Making simple prose pompous |
| **Technical Terminology** | Using field-standard terms correctly | Inserting jargon unnecessarily |
| **Connectives** | Academic transitions (however, moreover, consequently, thus) | Mechanical transition insertion |
| **Concise Expression** | Economical phrasing preferred in academic writing | Verbose "academic-sounding" language |

### Category Details

#### Reporting Verbs

Reporting verbs carry epistemic weight—they signal how confident the claim is:

| Verb | Evidence Level | Use When |
|------|----------------|----------|
| observed, noted | Neutral observation | Describing what was seen without interpretation |
| found, identified | Conclusion from data | Drawing a conclusion from evidence |
| showed, revealed | Clear evidence | Evidence strongly supports the claim |
| demonstrated | Strong evidence | Multiple lines of evidence support the claim |
| established, proved | Definitive | Causal mechanism confirmed with loss/gain/rescue |

#### Hedging Language

Hedging signals uncertainty appropriately:

| Hedge Level | Examples | Use When |
|-------------|----------|----------|
| Strong hedge | may, might, could, possibly | Speculation or preliminary data |
| Moderate hedge | suggests, indicates, appears to | Correlation or indirect evidence |
| Weak hedge | likely, probably | Strong but not definitive evidence |
| No hedge | demonstrates, establishes | Definitive causal evidence |

#### Formal Register

Academic register avoids:
- Contractions (don't → do not)
- Colloquial expressions (a lot of → numerous, considerable)
- Casual phrasing (got → obtained, received)
- Informal verbs (went up → increased, rose)

But maintains clarity—formal ≠ verbose.

#### Technical Terminology

- Use field-standard terms consistently
- Define abbreviations on first use
- Avoid unnecessary jargon that obscures meaning
- Ensure terminology is accessible to the journal's broad readership

#### Connectives and Transitions

Academic connectives signal logical relationships:

| Relationship | Examples |
|--------------|----------|
| Addition | moreover, furthermore, additionally |
| Contrast | however, conversely, in contrast, nevertheless |
| Cause/Effect | consequently, therefore, thus, as a result |
| Sequence | subsequently, following, initially |
| Example | specifically, for instance, notably |

#### Concise Expression

Academic writing values economy. Common reductions:

| Verbose | Concise |
|---------|---------|
| in order to | to |
| due to the fact that | because |
| a large number of | many |
| at this point in time | now, currently |
| has the ability to | can |
| in the event that | if |

## Intensity-Calibrated Vocabulary Editing

Match vocabulary editing to the determined editing intensity mode:

| Mode | Vocabulary Approach | Examples |
|------|---------------------|----------|
| **Light** | Fix only clearly colloquial or inappropriate vocabulary | "got" → "obtained"; obvious colloquialisms only |
| **Standard** | Upgrade vocabulary where it improves precision or professionalism | Systematic reporting verb calibration; improve informal register |
| **Intensive** | Systematically apply CNS-standard vocabulary throughout | Complete register upgrade; address all vocabulary categories |

## Principle-Based Examples

These examples show the **THINKING PROCESS**, not word-for-word substitutions. The goal is to understand the principle so it can be applied to new situations.

### Principle 1: Reporting Verbs Carry Epistemic Weight

```
ORIGINAL: "We saw that the protein went up"
→ "saw" is observational/informal; "went up" is colloquial

CONSIDER:
- "observed" (neutral observation)
- "found" (conclusion from data)  
- "demonstrated" (strong evidence)
- "established" (definitive proof)

CHOICE depends on evidence strength and context:
- If correlation only → "observed" or "found"
- If causal evidence → "demonstrated"
- If definitive mechanism → "established"

POSSIBLE EDITS:
✓ "We observed that protein levels increased" (neutral)
✓ "We found that protein levels increased" (conclusion)
✓ "We demonstrated that protein levels increased" (if strong evidence)
```

### Principle 2: Precision Beats Formality

```
❌ OVER-FORMAL: "We utilized a sophisticated methodology to investigate"
→ "utilized" adds nothing over "used"
→ "sophisticated" is vague self-praise
→ "investigate" is less precise than the actual method

✅ PRECISE: "We used single-cell RNA sequencing to identify"
→ Specific method named
→ Clear action verb
→ Professional but not pompous

KEY INSIGHT: A specific, simple word is always better than a vague, formal word.
```

### Principle 3: Colloquialisms Should Be Upgraded

```
❌ COLLOQUIAL: "The knockout mice got sick faster"
→ "got sick" is informal

✅ ACADEMIC: "Knockout mice exhibited accelerated disease onset"
→ "exhibited" is standard reporting verb
→ "accelerated disease onset" is precise

OTHER COMMON UPGRADES:
- "went up/down" → "increased/decreased"
- "a lot of" → "numerous" or specific number
- "got" → "obtained," "received," or "exhibited"
- "looked at" → "examined," "analyzed," "investigated"
- "things" → specific noun
```

### Principle 4: Don't Over-Formalize Clear Writing

```
❌ OVER-FORMALIZED: "It was observed that there was a significant 
                     elevation in the expression levels"
→ Unnecessarily wordy and passive
→ "elevation in the expression levels" is nominal bloat

✅ CLEAR AND ACADEMIC: "Expression increased significantly"
→ Direct, precise, and still professional
→ Uses active construction
→ Economical

KEY INSIGHT: Academic ≠ verbose. CNS editors actively cut wordiness.
```

### Principle 5: Match Register Throughout

```
❌ INCONSISTENT: "We utilized advanced techniques and got good results"
→ "utilized" is formal, "got good" is colloquial
→ Register mismatch is jarring

✅ CONSISTENT: "We used advanced techniques and obtained robust results"
→ Both clauses at same register level
→ Natural and professional
```

## Anti-Pattern: Pompous Prose

**Warning:** Academic vocabulary does NOT mean:

| Anti-Pattern | Problem | Better Approach |
|--------------|---------|-----------------|
| Using longer words when shorter ones are clearer | Obscures meaning | Use the clearest word |
| Nominalizing everything ("investigation of" instead of "investigating") | Creates passive, wordy prose | Use verbs actively |
| Passive voice everywhere | Obscures agency, adds words | Use active voice when appropriate |
| Unnecessary hedging or qualification | Weakens valid claims | Match hedging to evidence |
| Self-important language ("importantly," "interestingly," "strikingly") | Editorializing; CNS editors cut these | Let findings speak for themselves |

### The CNS Editor Test

**Ask:** Would a Cell/Nature/Science editor cut this word?

If yes → cut it.

Common words CNS editors cut:
- "Importantly," "Interestingly," "Strikingly," "Notably"
- "Very," "really," "quite" (as intensifiers)
- "It is well known that..." (just state the fact)
- "As mentioned above/previously" (usually unnecessary)
- Redundant pairs: "each and every," "first and foremost"

## Key Instruction

**Apply your knowledge of vocabulary conventions from published Cell, Nature, and Science papers.**

When editing, consider whether each word choice matches the vocabulary register found in these journals. Upgrade informal vocabulary but maintain precision—the goal is professional scientific communication that experts expect to read, not prose that tries to sound impressive.

**The three-part test for every word:**
1. Would this appear in CNS? (If not, upgrade)
2. Is this the most precise option? (Precision > formality)
3. Does this match the evidence strength? (Calibrate epistemic weight)

**Remember:** The goal is PUBLISHABILITY at CNS standards, not sounding academic. Clear, precise, professional prose—nothing more, nothing less.
